# clients_keys

Everything here is generated by **Register Clients** and is git-ignored.

| File | What it is |
|---|---|
| `<site>_private.pem`, `<site>_public.pem` | RSA key pair used to sign the JWT client assertion |
| `<site>_jwks.json` | The public key set registered with OpenEMR (the only file the web server will serve) |
| `client_<site>_<type>.json` | Client id, **client secret** and registered scopes for the JWT, confidential, public and smart clients |
| `scopelab_<site>_<grant>_<profile>.json` | Throwaway clients created by the Scope Lab |

Do not commit, zip up or share these files. To start over, delete them and run Register Clients
again. On nginx, block this folder yourself: the `.htaccess` only works on Apache.
